## SYNOPSIS

Checks if a Mocked command has been called a certain number of times
and throws an exception if it has not.

THIS COMMAND IS OBSOLETE AND WILL BE REMOVED SOMEWHERE DURING v5 LIFETIME,
USE Should -Invoke INSTEAD.

## SYNTAX

### ParameterFilter (Default)

```powershell
Assert-MockCalled [-CommandName] <string> [[-Times] <int>] [-ParameterFilter <scriptblock>]
 [-ModuleName <string>] [-Scope <string>] [-Exactly]
```
